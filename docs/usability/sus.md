# Ankieta SUS (System Usability Scale)

> **English summary:** Polish wording of the 10 standard System Usability Scale items (Brooke, 1996), the answer scale and the scoring formula (target score for Ucho: 75 or more). Content is in Polish because the participants are Polish.

SUS to dziesięć stwierdzeń opracowanych przez Johna Brooke'a (1996). Ankieta jest bezpłatna i powszechnie używana, więc wynik Ucho da się porównać z innymi programami. Poniżej wierne tłumaczenie oryginalnych stwierdzeń. Słowo „system” zastąpiono słowem „aplikacja”, co jest dopuszczalną i częstą praktyką. Kolejności stwierdzeń i skali nie zmieniamy: stwierdzenia nieparzyste są pozytywne, parzyste negatywne, i tak ma zostać.

Uczestnik wypełnia ankietę zaraz po zadaniach, zanim zaczniemy rozmawiać o wrażeniach. W rundzie 2 wypełnia ją osobno po każdym wariancie.

## Instrukcja dla uczestnika

> Przy każdym stwierdzeniu zaznacz, w jakim stopniu się z nim zgadzasz, myśląc o aplikacji, z której przed chwilą korzystałeś. Odpowiadaj szybko, pierwszym odczuciem. Odpowiedz na wszystkie stwierdzenia. Jeśli nie masz zdania, zaznacz środek skali (3).

Skala: **1** zdecydowanie się nie zgadzam, **2** raczej się nie zgadzam, **3** ani tak, ani nie, **4** raczej się zgadzam, **5** zdecydowanie się zgadzam.

| Nr | Stwierdzenie | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | Myślę, że chciał(a)bym często korzystać z tej aplikacji. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 2 | Aplikacja wydała mi się niepotrzebnie skomplikowana. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 3 | Uważam, że aplikacja była łatwa w użyciu. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 4 | Myślę, że do korzystania z tej aplikacji potrzebował(a)bym pomocy osoby znającej się na technice. | ☐ | ☐ | ☐ | ☐ | ☐ |
| 5 | Uważam, że poszczególne funkcje aplikacji dobrze ze sobą współgrały. | ☐ | ☐ | ☐ | ☐ | ☐ |

Pytanie otwarte (nie wchodzi do wyniku SUS):

> Co było najtrudniejsze?

## Oryginał (do sprawdzenia tłumaczenia)

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

## Jak liczyć wynik

Dla każdego uczestnika osobno:

1. Stwierdzenia **nieparzyste** (1, 3, 5, 7, 9): wkład = odpowiedź minus 1.
2. Stwierdzenia **parzyste** (2, 4, 6, 8, 10): wkład = 5 minus odpowiedź.
3. Zsumuj dziesięć wkładów (wynik od 0 do 40) i pomnóż przez 2,5.

```
SUS = 2,5 × [ (O1 − 1) + (5 − O2) + (O3 − 1) + (5 − O4) + (O5 − 1)
            + (5 − O6) + (O7 − 1) + (5 − O8) + (O9 − 1) + (5 − O10) ]
```

Wynik mieści się w przedziale od 0 do 100. **To nie jest procent**: 50 punktów nie oznacza „połowy użyteczności”.

Przykład: odpowiedzi 4, 2, 4, 1, 4, 2, 5, 2, 4, 3 dają wkłady 3, 3, 3, 4, 3, 3, 4, 3, 3, 2, razem 31, czyli SUS = 77,5.

Wynik zespołu to średnia z wyników uczestników. Przy 5 lub 6 osobach podajemy też najniższy i najwyższy wynik, bo pojedyncza osoba mocno zmienia średnią.

## Jak czytać wynik

| SUS | Interpretacja |
|---|---|
| poniżej 50 | poważne problemy, ludzie będą rezygnować |
| 50 do 67 | poniżej przeciętnej |
| około 68 | przeciętna (średnia z kilkuset badanych produktów) |
| **75 i więcej** | **cel dla Ucho**, dobra użyteczność |
| 80 i więcej | bardzo dobra, ludzie polecają produkt innym |

Brakująca odpowiedź: jeśli uczestnik pominie stwierdzenie, wpisujemy 3 (środek skali) i zaznaczamy to w raporcie.
